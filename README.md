# Interview Experiences Website (Frontend)

A responsive frontend website developed during my internship at **ITJOBXS** to organize and present company-wise interview experiences in a structured, accessible format.

## Overview

The Interview Experiences Website provides a centralized interface for exploring interview experiences and placement preparation resources. It features a navigation menu for online assessments, DSA roadmaps, OA roadmaps, job links, and coding communities.

## Live Demo

**[Visit the Interview Experiences Website](https://sivasuryakanth-maheshwaran.github.io/interview-experiences/html/index.html)**

## Tech Stack

- **HTML5** — Page structure and content
- **CSS3** — Styling and responsive layouts
- **Bootstrap** — UI components and layout
- **JavaScript** — Client-side interactivity

## Features

- Company-wise interview experience sections
- Navigation for online assessment resources
- DSA and online assessment roadmaps
- Job-related links and coding community resources
- Responsive user interface
- Company logos and visual assets

## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/SIVASURYAKANTH-MAHESHWARAN/interview-experiences.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `html/index.html` using the Live Server extension.
4. View the website in your browser.
